# 拾光相册 / Lumina

本地照片回忆整理应用：选中一个照片文件夹，用本机的 OpenAI 兼容视觉模型自动打分、打标签、写简评，再以「独立摄影杂志」式的拍立得画廊浏览、筛选、珍藏和搜索。

## 设计理念

- **像一本独立摄影杂志**：暖色纸张与胶片质感，拍立得卡片、留白与衬线排版，让整理旧照片这件事慢下来。
- **本地优先**：照片、评分和分析结果只保存在本机，没有账号也没有云端。唯一的联网行为是逆地理编码——带 GPS 的照片会把坐标发给所选服务换取地名，没有 GPS 的照片全程离线。
- **原图只读**：程序不会修改或覆盖原始照片文件，删除操作也只在用户明确确认后发生。

## 功能介绍

- 扫描常见图片格式，首次扫描建立索引并生成代理图，之后只处理还没评分的照片
- 本地视觉模型分析：标题、总分、技术 / 回忆 / 独特三项评分、中文标签与简评
- 画廊浏览：拍立得卡片网格，可在「全部 / 已收录 / 已珍藏 / 待整理 / 已收起」之间切换；打开一个只建过索引、还没有评分的文件夹时会自动切到「全部」，不会停在空页面
- 筛选与排序：最低分、标签、年份；按总分、拍摄时间、文件名、分析时间、文件大小排序
- 搜索：关键词、智能（关键词 + 语义）、语义三种模式
- 详情页：原图、相机参数（光圈 / 快门 / ISO / 焦距）、拍摄时间、地点、文件大小（有同名 RAW 时显示「图片 + RAW」两个数值）、三项评分条、标签与简评，支持上一张 / 下一张
- 全屏查看：滚轮缩放、拖拽平移、双击切换，`+` `-` `0` `Esc` 控制
- 珍藏、暂时收起、恢复、彻底移除；回收站可一键清空，清空过程同样有进度条
- 进度反馈：整理、同步、导入、清空回收站都会显示进度条与剩余时间估算；刷新页面不会打断任务，进度和估算会接着显示
- 编辑回忆：标题、总分与三项分项（滑块与输入框实时同步）、标签、地点、简评，不改动原文件
- 键盘快捷键：`←` `→` 切换照片、`F` 珍藏、`E` 编辑、`Esc` 关闭；文件路径可点击复制，也可用系统默认程序打开原图
- 分析语气预设：活泼（默认）、文艺、幽默、温暖、伤感
- 逆地理编码：Nominatim（免费）、高德地图（AMap），或选择「不使用」——带 GPS 的照片直接显示坐标，全程不联网
- 设置与界面状态都保存在数据库里，换浏览器或清除浏览器记录都不会丢失
- RAW 支持：同名的 JPG 与 RAW 视为一张照片（JPG 优先），只有 RAW 时用其内嵌的 JPEG 预览生成缩略图，卡片和详情页只做标记
- 竖拍照片按 EXIF 方向正确显示：缩略图与代理图都是正的，卡片和详情页不会再把竖构图横过来
- 从 SD 卡导入，并与卡上的照片保持同步（见「使用说明」）

## 使用说明

需要 Python 3.9+。

```bash
pip install -r requirements.txt
python app.py
```

浏览器打开 <http://127.0.0.1:5000>。

请先启动任意兼容 OpenAI Chat Completions 且支持图片输入的本地模型服务（LM Studio、Ollama、vLLM 等），然后在页面右上角「设置」中填写 API 地址、Key 和模型名。

日常流程：

1. 在顶部输入照片文件夹路径，或点击「浏览」选择文件夹；路径框右侧的小箭头可展开**整理过的文件夹**列表。
2. 点击「开始整理」：首次扫描建立索引并生成代理图，随后逐张调用模型分析。
3. 用统计卡、筛选、排序和搜索浏览回忆；点击卡片查看详情。
4. 红心珍藏，垃圾桶暂时收起，刷新图标重新解读，铅笔图标编辑回忆。在详情页里「暂时收起」会自动翻到下一张，收起最后一张时才关闭详情窗口。
5. 文件夹里有新增或删除时，点击「同步相册」增量更新，不会重复调用模型。

从 SD 卡导入：

1. 先选中本地的回忆文件夹（导入目标），再点击工具栏的「从 SD 卡导入」。
2. 选择卡上的目录（例如 `E:\DCIM`），按需调整下面几项。再次打开这个弹窗时会自动填上这个相册上次导入用的卡。
3. 点「预演」查看将要新增 / 覆盖的文件清单，确认后再点「开始导入」。

- **导入模式**：增量（默认，只拷卡上有、本地没有的文件）/ 全量（额外覆盖同名文件）
- **RAW 文件**：JPG+RAW（默认）/ 仅 JPG / 仅 RAW，卡上缺哪一半会自动用另一半补上
- **拷贝之后**：仅拷贝 / 建索引（默认，不调用模型）/ 索引 + 模型分析
- **覆盖时清除旧评分**（默认勾选）：全量模式替换了文件内容时，旧评分作废并回到「待整理」

本地有、卡上没有的照片不会被删除或修改，目录结构按卡上原样保留。导入过一次之后，这个本地目录会被记为该卡的**相机相册**：顶栏会显示 SD 卡状态，卡片在线时「暂时收起」可勾选「同步删除 SD 卡中的照片」，卡片不在时删除会被记录下来，下次插卡时带着预览一起补做。

## 配置说明

数据默认存放在仓库根目录下的 `data/`，数据库为 `data/library.db`。

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PHOTO_API_BASE_URL` | `http://localhost:1234/v1` | 模型 API 地址 |
| `PHOTO_API_KEY` | `not-needed` | API Key |
| `PHOTO_MODEL` | `local-model` | 模型名称 |
| `PHOTO_SYSTEM_PROMPT` | 空 | 自定义系统提示词（留空使用内置默认） |
| `PHOTO_PROXY_MAX_EDGE` | `1280` | 发送给模型的代理图最大边长 |
| `PHOTO_GALLERY_THUMB_SIZE` | `640` | 画廊缩略图最大边长 |
| `PHOTO_PROXY_QUALITY` | `80` | JPEG 代理图质量 |
| `PHOTO_THUMB_QUALITY` | `50` | 画廊缩略图 JPEG 质量 |
| `PHOTO_SCAN_CONCURRENCY` | `1` | 同时调用模型分析的照片数 |
| `PHOTO_INDEX_CONCURRENCY` | `4` | 建立索引 / 生成代理图的最大线程数 |
| `PHOTO_REQUEST_TIMEOUT` | `120` | 模型请求超时（秒） |
| `PHOTO_MODEL_RETRIES` | `3` | 单个模型请求失败后的重试次数（1 秒起翻倍） |
| `PHOTO_DATA_DIR` | 仓库根目录下的 `data` | 数据库目录 |
| `PHOTO_DB_PATH` | 空 | 直接指定数据库文件路径（覆盖 `PHOTO_DATA_DIR`） |
| `PHOTO_CACHE_DIR_NAME` | `.photo-review-cache` | 代理图缓存目录名 |
| `PHOTO_TRASH_DIR_NAME` | `.photo-trash` | 收起区目录名（本地与 SD 卡共用这个名字） |
| `PHOTO_GEOCODING_PROVIDER` | `nominatim` | 逆地理编码服务：`nominatim`、`amap`，或 `none`（不使用，直接显示坐标） |
| `PHOTO_GEOCODING_API_KEY` | 空 | 高德地图 Key（使用 `amap` 时填写） |
| `PHOTO_GEOCODING_INTERVAL` | `1.0` | 地理编码请求队列最小间隔（秒） |
| `PHOTO_GEOCODING_RETRIES` | `3` | 地理编码请求失败后的重试次数（1 秒起翻倍） |
| `PHOTO_HOST` | `127.0.0.1` | Web 监听地址 |
| `PHOTO_PORT` | `5000` | Web 监听端口 |
| `PHOTO_DEBUG` | `false` | Flask 调试模式（请勿在可被他人访问的地址上启用） |
| `PHOTO_ALLOWED_ORIGINS` | 空 | 额外允许调用写接口的来源，逗号分隔，例如 `http://192.168.1.9:5000` |

页面右上角「设置」按类别分成四个标签页，保存后写进数据库，重启依然生效：

- **大模型**：API Base URL、API Key、多模态模型名称、自定义系统提示词（可用活泼 / 文艺 / 幽默 / 温暖 / 伤感预设一键填入）、模型并发请求数、模型请求重试次数、请求超时
- **图片处理**：代理图片最大边长与质量、画廊缩略图边长与质量、索引线程数
- **地理编码**：地理编码服务（Nominatim / 高德 / 不使用）、API Key、请求间隔、重试次数
- **数据管理**：「移除当前目录」清除该目录的数据库记录与代理缓存（不动原图），「清理缓存」删除未被引用的代理图

`PHOTO_HOST` / `PHOTO_PORT` / `PHOTO_DEBUG` 只从环境变量读取，不会被数据库里的旧值覆盖。

## 开发

```bash
python -m unittest discover -s tests          # 后端：SQLite、扫描、导入、删除安全、方向修复
node tests/frontend_helpers.test.js           # 前端：进度/剩余时间/任务总结文案
ruff check app.py photo_reviewer tests
```

测试只用临时目录与假模型响应，不读取真实相册，也不需要联网。
